# Claude Code Configuration

## Plugins

The following plugins are enabled for this project:

- **typescript-lsp** — TypeScript language server integration for type checking, go-to-definition, and inline diagnostics
- **security-guidance** — Security best-practice enforcement and vulnerability detection (OWASP, injection, XSS, secrets exposure)
- **code-review** — Automated code review checks for correctness, maintainability, and consistency
